## ふなばし日和

千葉県船橋市のおすすめスポットを紹介する、スマートフォン対応の1ページサイトです。写真は `images/` に保存し、Unsplash License に基づくイメージ写真を掲載しています。各スポットの現地写真ではありません。

ページを開くとパスワード入力画面が表示されます。パスワードは `2784` です。間違えるたびにエラーメッセージが追加され、同じタブで10回間違えると404画面に切り替わります。404画面では管理者用パスワード `ick2522010` を入力した後、通常のパスワードを入力すると失敗回数がリセットされます。この仕組みはブラウザー内だけの簡易ロックで、パスワードや判定処理はHTMLから確認できます。機密情報の保護や実際のアクセス制限には利用しないでください。

### 表示方法

`index.html` をブラウザーで開くと表示できます。外部ライブラリやビルド手順は不要です。

スポットはカテゴリやキーワードで絞り込めます。「詳しく見る」から紹介を開き、地図へのリンクを利用できます。
